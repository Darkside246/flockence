# Flockence release requirements audit

This review references line numbers in the two briefs supplied on November 26, 2026. **In code** means the implementation is present in the release candidate. **Partial** means the line contains a capability with narrower coverage or insufficient field verification. **Open** means the release does not deliver it. GitHub CI, VPS deployment, live provider tests and hardware acceptance are separate checks.
